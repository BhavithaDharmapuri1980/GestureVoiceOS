GestureVoiceOS 🎙️✋



A gesture- and voice-controlled computer interaction project.



Features

Voice-based interaction

Hand gesture control

Frontend and backend architecture

Project Structure

backend/ — Backend application

frontend/ — Frontend application

Getting Started



Clone the repository:



git clone https://github.com/BhavithaDharmapuri1980/GestureVoiceOS.git

cd GestureVoiceOS





Start the frontend (if it uses npm and Vite):



cd frontend

npm install

npm run dev





Start the backend according to its framework and configuration.
